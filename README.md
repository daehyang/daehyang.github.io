# daehyang.github.io

대전향토문화연구회 공식 홈페이지. GitHub Pages(Jekyll)로 운영합니다.

## 글 쓰는 법 (회원용)

- 소식 글: `_posts/` 에 `YYYY-MM-DD-제목.md` 파일을 만들고 맨 위에
  ```
  ---
  title: 글 제목
  ---
  ```
  을 쓴 뒤 본문을 마크다운으로 작성합니다. 저장(커밋)하면 몇 분 안에 사이트에 반영됩니다.
- 고정 페이지 수정: `about.md`(소개) `journal.md`(회지) `projects.md`(사업)를 직접 고칩니다.

## 로컬 미리보기 (선택)

```
bundle install
bundle exec jekyll serve
```
