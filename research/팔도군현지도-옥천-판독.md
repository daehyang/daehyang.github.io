# 『팔도군현지도』 「충청도 옥천」 판독

『팔도군현지도』(古4709-111, 1767~1776) 가운데 옥천군 도엽. 옥천은 **회덕의 동쪽 이웃**이고,
이 도엽의 **서쪽 끝이 지금 대전 동구 세천·식장산**입니다.
계열의 생김새는 [`팔도군현지도-판독.md`](팔도군현지도-판독.md).

## **`遠峙` 가 여기에 있습니다** — 회덕과 짝이 맞습니다

| | 자리 |
|---|---|
| **회덕 도엽**(`_011`)의 `遠峙` | 도엽 **동쪽 끝**, `食莊山` 북 |
| **옥천 도엽**(`_012`)의 `遠峙` | 도엽 **서쪽 끝**, `懷德界` 안쪽 · `食莊山` 북 · `增若驛` 서 |

**한 지도책 안에서 이웃 두 고을이 같은 고개를 서로 적었습니다.**
대조표 4.2 의 「이웃이 서로를 적는 짝」은 지금까지 모두 **사지(四至) 거리**였는데,
이것은 **고개 이름**이 양쪽에 있는 첫 사례입니다.

> **그리고 `馬達峙` 쟁점에 닿습니다.** 1872년 「옥천군지도」는 **같은 자리**를
> **`馬達峙`** 로 적습니다 — 동구 세천동 ↔ 옥천 군북면 **증약리**(대조표 15.3).
> 이 도엽의 `遠峙` 도 **`增若驛` 바로 서쪽**입니다.
> **1770년대 `遠峙` ↔ 1872년 `馬達峙` 가 한 고개의 두 이름**일 수 있고,
> 대조표가 좌표로 잰 `遠峙` ↔ 마달령〔세천〕 **1.39 km**(6.9)와도 결이 같습니다.
>
> **단정하지 않습니다.** 두 이름을 잇는 직접 증언은 아직 없습니다 — 같은 자리를
> 가리키는 **이웃 관계**가 그렇다는 것까지입니다. 백제 `炭峴` 비정의 통설
> (「마도령 = 원치」)이 걸려 있는 자리이므로 더 조심합니다(6.9).

## 경계 — 열, **하나는 면 이름까지**

| 방위 | 표기 |
|---|---|
| 북 | `報恩界` |
| 북서 | `懷仁界` |
| **서북** | **`淸州周岸界`** |
| **서** | **`懷德界`** |
| 서남 | `珎山界` |
| 남서 | `錦山界` |
| 동북 | `靑山界` |
| 동 | `永同界` |
| 동남 | `黃澗界` |
| 남 | `茂朱界` |

**`淸州周岸界`** 는 면 이름(주안면)까지 적은 것입니다. **회덕 도엽은 같은 면을
`淸州周安界` 로 적습니다** — 한 책 안에서 `岸`/`安` 이 갈립니다.

**`珎山界` 와 `錦山界` 가 따로 있습니다** — 옥천이 진산·금산 둘 다와 닿습니다.

## 고개 — **여덟**, 이 계열에서 가장 많습니다

| 표기 | 자리 |
|---|---|
| **`遠峙`** | **서쪽 끝**, `懷德界` 안 · `食莊山` 북 · `增若驛` 서 |
| `長先峙` | 북, `報恩界` 쪽 |
| `文峙` | 북, `金積山` 서 |
| `靈音峙` | 북동, `安峙` 곁 |
| `安峙` | 북동, `安南面` 쪽 |
| `杻岺` | 동북 (색인 「유령」) |
| `葛峴` | 남동, `順陽驛` 북 |
| `加峙` | **남동 끝**, `茂朱界` 쪽 |

`長先峙` 는 회인 도엽에도 같은 이름이 있습니다(색인 「장선치」) — **두 고을 경계의
고개**로 보입니다. 확인하지 않았습니다.

## 남은 것

1. **`遠峙` = `馬達峙` 인가** — 두 이름을 잇는 직접 증언(『여지도서』·『옥천군읍지』 산천 조)
2. **`長先峙`** — 회인 도엽의 같은 이름과 같은 고개인지
3. **`杻岺`** 의 첫 글자 — `杻`(유)인가 `柚`인가
4. `淸州周岸界` 의 `岸`/`安` — 회덕 도엽과 다릅니다
