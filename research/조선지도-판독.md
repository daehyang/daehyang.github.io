# 『조선지도』 — 계열 길잡이

『조선지도(朝鮮地圖)』(규장각 **奎16030**, `GK16030_00`, **1767~1776**).
**방안식(方眼式)** 군현도 책이고, **같은 해의 『팔도군현지도』와 쌍둥이**입니다 —
그린 땅도 길도 거의 같은데 **고개 이름을 서로 다르게 고릅니다.**
**2026-10-05 에 열 장을 모두 읽었습니다.**

**도엽 한 장에 문서 하나**입니다. 이 문서는 **계열 전체에 걸리는 것**만 담습니다.

> **전라도가 없습니다.** 그래서 **진산·금산은 이 계열로 볼 수 없습니다** —
> 팔도군현지도도 우리가 받은 것은 충청도뿐이지만, 조선지도는 책 자체에 전라도가
> 빠져 있습니다(규장각 목록).

## 계열을 가로지르는 것

**① 경계에 면 이름을 다는 버릇은 여기도 있습니다** —
공주 **`淸州德坪界`** · 옥천 `淸州周岸界` · 회인 **`淸州周安面界`**.
**공주가 적은 `德坪面` 을 청주 도엽이 월경지로 그려** 두 도엽이 맞물립니다.

**② 청주만 가로 판형이고 월경지를 그립니다** — 8,043 px 폭.
서쪽 끝에 **`德坪面`** 이 길까지 갖춰 따로 그려져 있습니다.
**방안식이라 떨어진 자리를 종이 위 제자리에 놓을 수 있어서** 가능한 그림입니다.

**③ 이웃을 적고 안 적는 것도 갈립니다** —
**문의 도엽이 `懷德界` 를 적습니다**(팔도군현지도 문의에는 없음) →
**조선지도에서야 회덕↔문의 짝이 성립**합니다(대조표 4.2).
거꾸로 **연기 도엽은 `文義界` 를 빠뜨리고**, 옥천 도엽은 `懷德界` 를 빠뜨립니다.

**④ 길이 닿는 고개는 늘 일부입니다.**

| 고을 | 고개 | 길이 닿는 것 |
|---|---|---|
| 공주 | 8 | `車嶺`·`松峙`·`板峙`·**`揷峙`** 넷 |
| 회인 | 7 | `皮盤岺`·`墨峴` 둘 |
| 옥천 | 7 | `葛峙`·`加峙` 둘 |
| 연산 | 5 | `沙峴` 하나 |
| 문의 | 2 | `栗峙` 하나 |
| 연기 | 1 | **`松峴` 하나 — 외길** |
| 회덕 | 3 | `東峙` 하나 |
| 진잠 | **0** | 길은 셋인데 **고개 이름이 없습니다** |

**진잠이 가장 또렷한 사례입니다** — 읍치에서 길이 셋으로 갈리는데 **고개 이름을
하나도 적지 않습니다.** 대조표 6.5 의 「길목 이름과 안부 이름은 세는 단위가 다르다」에서,
**이 계열은 둘 다 적는 데 인색합니다.**

**⑤ 글자가 잘게 갈립니다** — `珍`/`珎` · `雞`/`鷄` · `葛峙`/`葛峴` · `土坡`/`土破` ·
`申灘`/`市灘` · `皇華山`/`白華山` · `芼村里`/`芼村面`.
**두 책이 서로 베낀 것이 아니라 공통 저본을 각자 옮긴 것**으로 보입니다.

## 남은 것

1. **두 방안식의 계통 관계** — 어느 쪽이 먼저인가. `質峙`·`遠峙` 를 뺀 쪽과 적은 쪽
2. **청주 고개 넷의 글자**(`杉`·`屛`·`杻`·`栗`) — 확신 `하`
3. **`德目峙` 가 방안식 둘에 다 없는 까닭**
4. **`熊峙`** — 청주와 회인에 같은 이름이 있습니다. 같은 고개인지
5. 월경지 `德坪面` 의 둘레 지명
