# crops — 판독 근거로 잘라 둔 그림

**쟁점의 근거가 되는 조각만** 둡니다. 원본 도엽은 두지 않습니다 — 원본은 위키미디어 공용에
있고 주소가 영구적입니다([`../고지도-목록.md`](../고지도-목록.md)).

판독은 자주 뒤집힙니다. 뒤집을 때 근거 그림이 저장소 안에 있어야 다른 사람이 바로
확인합니다. 이슈 댓글에만 붙여 두면 흩어져서 나중에 찾기 어렵습니다.

## 규칙

- **한 장 500 KB 이내.** 넘으면 판독에 필요한 만큼만 더 잘라 내거나 폭을 줄입니다
- **파일 이름에 자른 자리를 넣습니다** — `<자료번호>_x<왼쪽>_y<위>_w<폭>_h<높이>.jpg`
  ```
  KYKH002_0000_0046_x0.68_y0.26_w0.10_h0.12.jpg
  ```
  값은 도엽 폭·높이를 각각 1로 본 상대 좌표입니다. 이렇게 적으면 **누구나 커먼즈 원본에서
  같은 자리를 다시 자를 수 있습니다.** 자세한 것은 [`../판독-기록-형식.md`](../판독-기록-형식.md)
- **어딘가에서 참조되지 않는 그림은 두지 않습니다.** 문서나 이슈에서 걸리지 않는 조각은
  나중에 무엇이었는지 알 수 없게 됩니다
- **출전은 그림이 아니라 기록에 적습니다.** 파일만 남으면 어느 도엽에서 왔는지 알 수 없습니다

## 왜 500 KB 인가

원본은 한 장에 12~83 MB 입니다(열한 종 합계 약 558 MB). git 은 한 번 커밋한 파일을 지워도
히스토리에 남기므로, 원본을 올리면 되돌릴 수 없습니다. 판독에 쓰는 조각은 글자가 읽히면
되므로 그보다 백 배 작아도 충분합니다.

## 이 폴더는 사이트에 나가지 않습니다

`_config.yml` 의 `exclude` 에 `research` 가 들어 있습니다.
