# images — 지도 확대·잘라낸 그림

판독에 쓴 지도 조각을 둡니다. 문서 본문에서 `![설명](images/파일명.jpg)` 으로 겁니다.

## 규칙

- 파일명은 `<자료>-<대상>.jpg` — 예: `해동지도-회덕현-우치령.jpg`
- **원본 전체 도엽은 넣지 않습니다.** 판독에 필요한 부분만 잘라 둡니다. 저장소가 무거워지고,
  소장 기관의 이용 조건도 자료마다 다릅니다.
- **출처는 문서 본문에 적습니다.** 파일만 남으면 어디서 온 그림인지 알 수 없게 됩니다.
- 이 디렉터리는 사이트에 나가지 않습니다 (`_config.yml` 의 `exclude` 에 `research` 가 있음).

## 넣는 방법

- **웹에서** — 이 폴더에서 `Add file → Upload files` 로 끌어다 놓습니다. 클론이 필요 없습니다.
- **PR·이슈 댓글에** — 그림을 댓글에 끌어다 놓으면 바로 붙습니다. 다만 그렇게 붙인 그림은
  저장소가 아니라 GitHub 쪽에 저장되므로, 오래 남길 것은 이 폴더에 따로 올립니다.
