# research — 조사 작업 자료

발간 전 조사 자료를 두는 곳입니다. **사이트에는 나가지 않습니다** — `_config.yml` 의
`exclude` 에 `research` 가 들어 있어 Jekyll 이 이 디렉터리를 내보내지 않습니다.
저장소에서는 누구나 볼 수 있지만 홈페이지에는 실리지 않습니다.

## 작업 방식

- **GitHub 브랜치에서 직접 고칩니다.** 이 디렉터리에 한해 `main` 직접 푸시 대신 브랜치를
  씁니다. 저장소 기본 규칙(`../CLAUDE.md`)의 예외입니다 — 여러 사람이 같은 문서를 이어
  고치는 자료라 중간 상태가 그대로 배포되면 곤란하기 때문입니다.
- 지금 쓰는 작업 브랜치: `claude/haedong-map-place-names-cx7g74`
- 조사 단락이 끝나면 `main` 으로 병합합니다. 병합해도 사이트에는 영향이 없습니다
  (`exclude` 때문에).

## 이미지

지도 확대·잘라낸 그림은 **`research/images/`** 에 둡니다.

- 파일명은 `<자료>-<대상>.jpg` — 예: `해동지도-회덕현-우치령.jpg`
- 원본 전체 도엽은 넣지 않습니다. 판독에 필요한 부분만 잘라 둡니다
  (저장소가 무거워지고, 소장 기관의 이용 조건도 자료마다 다릅니다).
- 그림을 넣으면 문서 본문에서 상대 경로로 겁니다 — `![설명](images/파일명.jpg)`

## 지켜야 할 것

- **여기는 공개 저장소입니다.** 개인 연락처, 미공개 회의 내용, 발간 전 원고를 넣지
  않습니다. 그런 것은 `internal` 저장소에 둡니다.
- **front matter 를 넣지 않습니다.** front matter 가 없으면 Jekyll 이 정적 파일로 다루고,
  `exclude` 와 겹쳐 이중으로 안전합니다. Liquid 태그(`{`+`{`, `{`+`%`)도 쓰지 않습니다.
- **조사 메모는 확정 자료가 아닙니다.** 각 문서 첫머리에 그 사실을 적어 둡니다.
- **대장은 여기서 고치지 않습니다.** 근거가 갖춰진 항목은 `internal` 저장소의
  "지명 등재 발의" 이슈로 넘깁니다. 확정된 값은 [공개 목록](https://daehyang.github.io/placenames/)에
  실립니다.
