# research — 조사 작업 자료

발간 전 조사 자료를 두는 곳입니다. **사이트에는 나가지 않습니다** — `_config.yml` 의
`exclude` 에 `research` 가 들어 있어 Jekyll 이 이 디렉터리를 내보내지 않습니다.
저장소에서는 누구나 볼 수 있지만 홈페이지에는 실리지 않습니다.

| | 곳 |
|---|---|

## 고치는 방법

- **`main` 에 바로 고칩니다.** 이 저장소의 규칙 그대로입니다(`../CLAUDE.md`). 조사 문서도
  예외가 아닙니다 — 사이트에 나가지 않으므로 잘못 적어도 홈페이지가 상하지 않습니다.
  GitHub 웹에서 문서를 열고 연필 아이콘을 누르면 바로 고칠 수 있습니다.
- 다만 **사이트에 나가는 파일**(`_config.yml`, `_layouts/`, 페이지 `.md`)을 함께 건드렸다면
  푸시 전에 로컬 빌드로 확인합니다. 방법은 `../CLAUDE.md` 의 "로컬 빌드".
- 고친 내용은 문서 끝 **변경 이력**에 한 줄 남깁니다.

## 의논은 Issues 로

문서 안에서 말다툼하지 않습니다. **쟁점 하나가 이슈 하나**입니다.

- 고개 한 건의 비정, 글자 판독, 자료 하나의 채록 — 각각 이슈를 엽니다.
- 결론이 나면 문서에 반영하고 이슈를 닫습니다. **문서에는 결론과 근거만, 오가는 말은
  이슈에** 남깁니다.
- 이슈 댓글에는 **그림을 끌어다 놓을 수 있습니다.** 판독하려고 확대한 사진은 여기 붙입니다.
- 남은 일을 문서 안에 체크리스트로 만들지 않습니다. 가장 자주 바뀌는 것을 문서에 두면
  문서가 낡습니다.

### 라벨

이 저장소는 홈페이지 저장소이기도 해서 사이트 문제와 조사 이슈가 섞입니다. 그래서 셋만 둡니다.

| 라벨 | 색 | 붙이는 것 |
|---|---|---|
| `고개조사` | `0E5A8A` | 고개 지명 조사에 관한 모든 이슈 |
| `제보환영` | `0E8A16` | 고지도를 못 읽어도 답할 수 있는 것. **회원께 안내할 때 이 라벨을 가리킵니다** |
| `홈페이지` | `6E5494` | 사이트 자체 문제 — 페이지·레이아웃·배포 |

`internal` 의 라벨 6종(`회지` `위키데이터` `지명등재` `행사` `총무` `회의`)과 겹치지 않게 했습니다.
**새 라벨은 꼭 필요할 때만 늘립니다.** 이슈가 스무 개를 넘어가면 조사 성격으로 나누는 것이
쓸모 있어집니다 — 그때 `판독`(글자 읽기) · `비정`(위치 정하기) · `채록`(자료에서 뽑기) 을
더할 만합니다. 지금은 이릅니다.

## 그림 — 올리지 않고 링크로 겁니다

**지도 이미지를 이 저장소에 올리지 않습니다.** 고지도 스캔본은 한 장에 수십 MB 이고,
git 은 한 번 커밋한 파일을 지워도 히스토리에 영구히 남깁니다. 대신 **위키미디어 공용
(Wikimedia Commons)에 있는 것을 링크로** 겁니다.

주소는 두 가지를 함께 적습니다.

| 쓰임 | 주소 틀 |
|---|---|
| 그림을 본문에 걸 때 | `https://commons.wikimedia.org/wiki/Special:FilePath/<파일명>?width=1000` |
| 출처·라이선스를 가리킬 때 | `https://commons.wikimedia.org/wiki/File:<파일명>` |

```
[![진산군지도](https://commons.wikimedia.org/wiki/Special:FilePath/<파일명>?width=1000)](https://commons.wikimedia.org/wiki/File:<파일명>)
```

- 파일명의 한글·괄호는 URL 인코딩합니다(`전` → `%EC%A0%84`). 커먼즈 파일 문서에서
  주소를 복사하면 이미 인코딩되어 있습니다.
- `?width=` 로 크기를 줄여 겁니다. 원본은 수천 픽셀이라 그대로 걸면 문서가 무겁습니다.
- **출전은 링크가 아니라 자료명과 소장처로 적습니다.** 커먼즈 파일은 지워지거나 이름이
  바뀔 수 있습니다. 링크가 깨져도 무엇을 본 것인지 남아 있어야 합니다.
- 커먼즈에 없는 자료는 링크하지 말고 **어디서 볼 수 있는지만** 적습니다(규장각 등).
  기관 원문 뷰어는 주소가 자주 바뀌어 링크가 오래가지 않습니다.

## 지켜야 할 것

- **여기는 공개 저장소입니다.** 개인 연락처, 미공개 회의 내용, 발간 전 원고를 넣지 않습니다.
  그런 것은 `internal` 저장소에 둡니다.
- **front matter 를 넣지 않습니다.** 없으면 Jekyll 이 정적 파일로 다루어 `exclude` 와 겹쳐
  이중으로 안전합니다. Liquid 태그도 쓰지 않습니다.
- **조사 메모는 확정 자료가 아닙니다.** 각 문서 첫머리에 그 사실을 적어 둡니다.
- **대장은 여기서 고치지 않습니다.** 근거가 갖춰진 항목은 `internal` 저장소의
  "지명 등재 발의" 이슈로 넘깁니다. 접근 권한이 없으시면 연구회로 알려 주십시오.
