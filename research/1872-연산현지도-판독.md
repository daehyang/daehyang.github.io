# 1872년 「충청도 연산현지도」 판독

**연산은 진잠(대전 유성·서구 남부)의 서남쪽 이웃**입니다. 지금 논산시 연산면입니다.

진산은 색칠한 네모(노랑·빨강·파랑), 금산은 색 네모에 면마다 색을 달리, 문의는 색 네모,
연산은 빨간 네모입니다.

## 도로 주기 — 오른쪽 세로

```
全羅道全州界二十里

恩津界十五里
```
